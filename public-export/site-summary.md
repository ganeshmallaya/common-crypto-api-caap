# Crypto Agility Algorithm Protocol (CAAP)

CAAP is an independent research framework for a vendor-neutral cryptographic
abstraction layer. The Common Crypto API gives applications a stable
operation-and-intent contract while a broker enforces a separate policy
decision across software libraries, HSMs, KMSs, key stores, PKCS#11, and KMIP.

Framework v1 is an exploratory proposal. It is not a standard, implementation,
conformance claim, or statement of industry adoption.
